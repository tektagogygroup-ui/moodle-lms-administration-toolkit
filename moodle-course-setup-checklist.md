# Moodle Course Setup and Quality Assurance Checklist

**Document Type:** LMS Administration and Course Quality Assurance  
**Prepared by:** Damaris  
**Organisation:** TEKTAGOGY Group  
**Platform:** Moodle LMS

---

## 1. Course Configuration

- [ ] Confirm the correct course name and short name.
- [ ] Verify the course category.
- [ ] Confirm the course start and end dates.
- [ ] Select the appropriate course format.
- [ ] Review course visibility and availability.
- [ ] Verify course description and learning objectives.
- [ ] Confirm the correct semester or academic period.

## 2. User Enrolment and Access

- [ ] Confirm lecturer enrolment.
- [ ] Verify student enrolment.
- [ ] Check assigned user roles.
- [ ] Confirm enrolment methods.
- [ ] Verify course access permissions.
- [ ] Test access using an appropriate student test account.

## 3. Learning Materials

- [ ] Confirm that learning materials are uploaded.
- [ ] Check document accessibility.
- [ ] Verify that resource links work.
- [ ] Organise learning materials into appropriate sections.
- [ ] Check consistency of course labels and headings.
- [ ] Confirm that learning resources are accessible to students.

## 4. Assignments and Assessments

- [ ] Verify assignment instructions.
- [ ] Confirm assignment availability dates.
- [ ] Check submission deadlines.
- [ ] Verify accepted submission types.
- [ ] Review grading settings.
- [ ] Confirm quiz availability dates.
- [ ] Check quiz time limits and attempt allowances.
- [ ] Review question behaviour and navigation settings.
- [ ] Verify question bank configuration.
- [ ] Test assessment access and submission using a test account.

## 5. Communication and Student Support

- [ ] Confirm course announcements are available.
- [ ] Check discussion forums where applicable.
- [ ] Verify lecturer contact information.
- [ ] Confirm student support instructions.
- [ ] Check notification settings.

## 6. Course Quality Assurance

- [ ] Confirm consistency between course objectives and learning activities.
- [ ] Review completeness of learning materials.
- [ ] Check assessment alignment with learning outcomes.
- [ ] Verify that all course activities are accessible.
- [ ] Check for broken links and missing files.
- [ ] Review course organisation and navigation.
- [ ] Confirm that students can access required activities.
